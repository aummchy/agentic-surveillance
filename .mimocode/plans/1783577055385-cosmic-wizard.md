# Plan: Fix 2 Logging Bugs in 3-Tier Logger

## Bug 1: None lines + structlog RuntimeWarning

**Error:** `RuntimeWarning: The last processor in ProcessorFormatter.processors must return a string, but CompactTerminalRenderer returned NoneType instead.`

**Cause:** `CompactTerminalRenderer.__call__()` and `_format()` return `None` for suppressed events. structlog requires a string.

**Fix:** Return `""` instead of `None`.

## Bug 2: _BlankFilter overly complex

**Current:** _BlankFilter checks allowlist + event name + blank string.

**Fix:** Simplify to only filter blank strings. The renderer now always returns a string, so just check if it's empty.

## Changes

### 1. `config/settings.py` — Fix CompactTerminalRenderer.__call__()

```python
def __call__(self, logger, method_name, event_dict):
    event = event_dict.get("event", "")
    show = event in TERMINAL_ALLOWLIST
    if method_name in ("warning", "error", "critical"):
        show = True
    if not show:
        return ""
    return self._format(event_dict)
```

### 2. `config/settings.py` — Fix _format() to always return string

Remove the `return None` check at the start of `_format()`. The `__call__` method already handles suppression.

### 3. `config/settings.py` — Simplify _BlankFilter

```python
class _BlankFilter(logging.Filter):
    def filter(self, record):
        msg = record.getMessage()
        return bool(msg and msg.strip())
```
